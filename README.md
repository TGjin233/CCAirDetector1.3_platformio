# CC Air Detector V1.3

基于 ESP32 的智能空气质量监测仪，支持温湿度监测、天气信息、股票指数显示等功能。

## 功能特性

- **环境监测**：温度、湿度、TVOC、甲醛、CO2、AQI
- **天气信息**：实时天气、空气质量（和风天气API）
- **股票指数**：上证、深证、创业板、纳斯达克等
- **多页面显示**：数据页面、日历、动画等9种页面
- **WiFi配网**：Web页面配置，支持OTA更新

## 硬件配置

| 功能 | GPIO | 说明 |
|------|------|------|
| 屏幕背光 | 17 | PWM调光 |
| 蜂鸣器 | 13 | 声音提示 |
| 按钮1 | 25 | 左移 |
| 按钮2 | 26 | 确定 |
| 按钮3 | 27 | 右移 |
| BOOT按键 | 0 | 系统按键 |
| JW01开关 | 12 | 传感器电源 |

## 开发环境

- **平台**：PlatformIO + Arduino框架
- **开发板**：ESP32-CAM
- **屏幕**：TFT_eSPI驱动

## 快速开始

1. 安装 PlatformIO IDE
2. 克隆本项目
3. 修改 `src/Common.h` 中的配置
4. 编译上传

## 配置说明

### WiFi配置
首次使用需通过Web页面配置WiFi：
1. 开机进入配网模式
2. 连接设备热点
3. 访问配置页面输入WiFi信息

### 开发者模式
修改 `src/Common.h`：
```cpp
#define DEVELOP_MODE true  // 启用开发者模式
```
开发者模式跳过配网，直接进入指数页面。

### 股票指数
修改 `src/nowAPI.cpp` 中的关注列表：
```cpp
const char* WATCHED_INDICES[] = {
  "sh000001",    // 上证指数
  "sz399001",    // 深证成指
  "gb_ixic",     // 纳斯达克
};
```
